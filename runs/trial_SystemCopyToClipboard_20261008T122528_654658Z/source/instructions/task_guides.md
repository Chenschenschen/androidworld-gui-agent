# Warm-up procedures v1

These are task-specific procedural recommendations authorized by the user.
Choose one action from the CURRENT observation. Use a fresh observed control
centre when its label matches the intended control; otherwise locate it in the
screenshot. The guide never supplies fixed coordinates or executes a sequence.

## SystemWifiTurnOn
Start in Settings. Open Network & internet, then Internet (or the visible Wi-Fi
page). Locate the Wi-Fi switch. Read its checked state in the fresh observation:
OFF means tap the switch once; ON means leave it alone. After tapping, observe
again. Finish when Wi-Fi is ON. You do not need a network connection, password
or selected network. Do not toggle an already-ON switch to demonstrate success.

## CameraTakePhoto
Start in Camera. Wait for the live preview and visible shutter if the app is
loading; a blank loading frame is not a ready camera. Use Photo mode. Identify
the photo shutter in the current screenshot, not the gallery thumbnail. Take
exactly one photo, then inspect the new thumbnail/preview and executed history.
Finish when one shutter action produced a new photo. Do not press the shutter
again just because you are uncertain; first inspect the observed result.

## ClockTimerEntry
Start in Clock and open Timer. The timer keypad is a RIGHT-ALIGNED digit buffer:
each tap appends one digit and shifts earlier digits left across HH:MM:SS.
It is not three independently editable fields. Use the exact HHMMSS input value
and target display provided in the completion condition. Before EACH digit tap,
compare the observed buffer with the intended input prefix and choose the next
digit yourself. For this task the target is {timer_display} and the complete
input is {timer_input}: {timer_sequence}. Use that task-specific sequence;
do not keep tapping 0 until hours look right.
If the buffer is not an intended prefix, use the visible Delete control to
remove the incorrect suffix and observe again. A full wrong six-digit buffer
cannot be repaired by appending more digits. Tap keypad digits individually;
Type is only for a focused editable text field. Finish only when ALL displayed
hours, minutes and seconds match the target and the timer remains unstarted.
Do not press Start.

## ContactsAddContact
Start in Contacts. Open Create contact. Enter the requested name in the visible
name field(s), splitting given/family names only if the form separates them.
Preserve every part of the requested name. Enter the exact requested number in
the actual Phone field. Use Type on a
focused editable field; it replaces that field's text without pressing Enter.
Avoid suggestions, account selectors and nearby labels. Scroll only if the
needed field or Save is not visible. Check the filled values, then choose Save
once. Inspect the saved contact's displayed name and number. Finish on the
saved record with the exact requested values, not on the unsaved form.

## SystemCopyToClipboard
Start in Markor, a text editor. Use the visible QuickNote tab to open its editable
text area; if already in that editor, keep using it. Focus the actual editor and
Type the exact task input clipboard_content. Verify that the editor contains
that complete text.
Long press INSIDE that editor. A long press may select only one word or a domain;
that is not enough. Choose Select all in the text-selection toolbar (or its
overflow), then inspect the highlight/selection handles: every character of the
requested string must be selected. Choose the selection toolbar's Copy command.
Finish only after that full-text selection was copied. If a clipboard preview
is visible, check it too; merely closing a menu is not proof of a full-value copy.
You do not need a clipboard-manager app, browser menus, a URL search, a recipient
or an SMS. Clipper is verifier infrastructure. Do not send/share the text.
